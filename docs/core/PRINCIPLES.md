## Engineering Principles

1. **Documentation leads code**: Design decisions are documented before they are implemented. Code follows documented architecture.

2. **Single source of truth**: Each concept, term, or decision is defined in exactly one place.

3. **Explicit over implicit**: Prefer clear boundaries, typed interfaces, and documented contracts over convention or magic.

4. **Incremental delivery**: Build in small, shippable increments. Each increment must be functional and tested.
